Your Stoker apps run on Google Cloud projects, which are also Firebase projects.

The following advanced features are available in your Google Cloud projects:

| Feature | Details |
| --- | --- |
| Firebase Auth Email Templates | Customize the email templates used for auth actions in the Firebase Console. Settings are under Authentication > Templates. |
| Firebase Integrations | There are a number of services that your Firebase (Google Cloud) projects can integrate with. See "Integrations" in the "Project Settings" section of the Firebase Console. |
| Project Alerts | Firebase sends alerts regarding your Firebase (Google Cloud) projects. You can enable or disable these under "Alerts" in the "Project Settings" section of the Firebase Console. |
